# VEHICLE TRACKER

## Description
Vehicle Tracker is a machine learning project using YOLOv8n model to detect and track moving vehicles in the given video and calculate their speed.

## Requirements

`python 3.10`

```text
opencv-python
ultralytics
numpy
```

### Install packages
```bash
pip install -r requirements.txt
```
